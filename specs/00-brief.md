# Product Brief

Open Source Project Intelligence turns repository, contributor, issue, pull-request, release,
documentation, registry, advisory, and package evidence into explainable technical-adoption
intelligence. It is not a GitHub dashboard and it is not a chatbot over provider responses.

The complete accepted delivery serves anonymous visitors, Applicants, Viewers, Analysts, Admins,
service accounts, and VPS Operators. It covers project registration and lifecycle, incremental
collection, deterministic metrics, comparisons, health, policies and radar, topic and release
intelligence, evidence-backed AI analysis, alerts, exports, audit, and operations.

The product starts as a modular monolith with separate Go API and worker processes plus a React web
application. PostgreSQL is authoritative. Every external provider, model, broker, cache, identity
system, and object store is reached through a bounded adapter. Deterministic algorithms own facts,
scores, ranges, checkpoints, and lifecycle decisions; models may interpret evidence but never invent
or replace those results.

Completion means the whole numbered specification and test contract pass together. Intermediate
vertical slices are implementation checkpoints, not accepted product releases.
